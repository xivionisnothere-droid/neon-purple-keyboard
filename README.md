# Neon Purple Keyboard

Custom purple neon gothic Android keyboard with suggestion bar, symbol mode, and safe autocorrect.

## Features
- Purple neon gothic style with flowing animation
- Suggestion bar as you type
- Switch between letters and symbols (! ? # etc.) with the !#1 / ABC key
- Emoji key (😊)
- Safe autocorrect (only fixes clear typos)
- Haptic feedback

## Install
1. Download the APK below or from the releases
2. On your Samsung: Settings > Apps > Special access > Install unknown apps > allow your browser/files app
3. Install the APK
4. Settings > General management > Keyboard list and default > Enable Neon Purple Keyboard
5. Switch to it in any text field

## Notes
- Uninstall previous versions first
- Symbol mode and emoji are now functional
